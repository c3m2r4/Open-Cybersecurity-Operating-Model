# Security Awareness Domain

## Executive Summary

Security awareness reduces human-centered risk by improving security culture, reporting behavior, role-specific knowledge, and practical decision-making.

## Beginner

Security awareness helps people recognize risky situations and know what to do, such as reporting a suspicious email or protecting sensitive information.

## Practitioner

Core practices include phishing awareness, social engineering awareness, role-based training, privileged-user training, developer security training, incident reporting, onboarding/offboarding content, and measurement.

## Security Professional

Awareness should not be treated as merely annual training completion. Better outcomes include faster reporting, fewer repeat risky behaviors, improved handling of sensitive data, better developer decisions, and stronger privileged-user discipline.

## Evidence

Evidence includes training assignments, completion reports, phishing simulation outcomes, reported phishing messages, incident reporting metrics, role-based training records, developer training records, and corrective action records.

## Metrics

| Metric | Type | Notes |
|---|---|---|
| Phishing report rate | KPI / KCI | Useful behavioral signal |
| Repeat click rate | KRI | Must be handled constructively |
| Role-based training coverage | KCI | Scope - VERIFY |
| Incident reporting volume | KPI / KRI | Interpret with quality and context |
| Developer secure coding training coverage | KCI | Relevant to application teams |

## Management View

Security culture affects incident reporting, fraud prevention, data handling, and resilience. Management should support practical, role-based education rather than relying only on annual completion statistics.
