# Information Security - Index

Use this area for the major security domains that own day-to-day protection of systems, identities, networks, applications, cloud services, and data.

## Domains

| Domain | Typical Questions |
|---|---|
| [[Identity and Access Management]] | Who has access, why, and how is it controlled? |
| [[Network Security Domain]] | How are systems segmented, exposed, filtered, and monitored? |
| [[Endpoint Security Domain]] | Are endpoints hardened, patched, monitored, and recoverable? |
| [[Email Security Domain]] | Can phishing, spoofing, and malicious content be prevented or detected? |
| [[Data Security Domain]] | Where is sensitive data, who can access it, and how is it protected? |
| [[Application Security Domain]] | Are applications designed, built, tested, and operated securely? |
| [[Cloud Security Domain]] | Are cloud identities, networks, workloads, and data governed? |
| [[Vulnerability Management Domain]] | Are weaknesses found, prioritized, fixed, and verified? |
| [[Security Monitoring Domain]] | Are important events logged, detected, triaged, and responded to? |
| [[Security Awareness Domain]] | Are users trained against realistic risks? |

## Operating Relationship

```text
Business Objective
  -> Business Asset
  -> Threat
  -> Risk
  -> Control Objective
  -> Security Control
  -> Implementation
  -> Control Test
  -> Evidence
  -> Control Effectiveness
  -> Residual Risk
  -> Management Decision
```
