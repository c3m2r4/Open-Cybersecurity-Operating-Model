# Glossary

| Term | Working Definition |
|---|---|
| Asset | Something valuable that must be protected, such as data, identity, system, process, or service. |
| Threat | A potential cause of harm to an asset. |
| Vulnerability | A weakness that could be exploited by a threat. |
| Risk | The effect of uncertainty on objectives, usually expressed through likelihood and impact. |
| Control | A safeguard that prevents, detects, or corrects a risk condition. |
| Control Test | A planned activity used to evaluate whether a control is designed and operating effectively. |
| Offensive Validation | Authorized testing that demonstrates how a weakness could be abused. |
| Detection Validation | Testing that confirms whether telemetry, alerts, triage, and response work as expected. |
| Residual Risk | Risk remaining after controls and treatment actions are applied. |
| Risk Acceptance | A management decision to tolerate residual risk. |
| Evidence | Records, logs, screenshots, commands, observations, or artifacts that support a conclusion. |
| Finding | A documented issue that includes condition, risk, evidence, impact, remediation, and owner. |
| Inherent Risk | Risk before considering current controls. |
| Control Effectiveness | A judgment about whether a control is suitably designed and operating as intended. |
| Risk Owner | The person accountable for deciding how a risk should be treated. |
| Control Owner | The person or function accountable for operating and maintaining a control. |
| Risk Treatment | The decision to mitigate, accept, transfer, or avoid risk. |
| KPI | Key Performance Indicator; a measure of process performance or delivery. |
| KRI | Key Risk Indicator; a measure that signals exposure or risk movement. |
| KCI | Key Control Indicator; a measure that signals whether a control is operating. |
| Aligned To | Consistent with the intent of a framework or standard. This is not the same as compliant with it. |
| Compliant With | Demonstrably meeting defined requirements, usually supported by formal evidence and assessment. |
