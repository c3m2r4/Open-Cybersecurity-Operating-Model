# Professional Content Standard

## Purpose

This standard defines how notes in this vault should be written. The goal is defensible professional content, not volume.

## Writing Standard

Every substantial note should be:

| Quality | Requirement |
|---|---|
| Accurate | Do not invent facts, results, incidents, configurations, or compliance status |
| Useful | Include information a practitioner can act on or management can decide from |
| Clear | Explain terminology before relying on it |
| Evidence-aware | Separate known facts from assumptions and recommendations |
| Version-aware | Mark product, standard, or framework details that may change over time |
| Scope-aware | State when guidance applies only to labs, examples, or a specific environment |
| Linked | Connect risk, control, validation, detection, remediation, and decisions where useful |

## Source Labels

| Label | Use When |
|---|---|
| Industry Standard | The statement reflects recognized professional practice or a recognized framework |
| Professional Judgment | The statement is a reasoned recommendation based on risk and security principles |
| Lab-Verified | The statement is supported by evidence from an authorized lab note |
| Research | The statement depends on external research and should include references |
| Assumption | The statement is plausible but not yet verified in this vault |
| Recommendation | The statement proposes a treatment or improvement |
