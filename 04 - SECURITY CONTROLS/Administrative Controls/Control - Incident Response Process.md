# Control - Incident Response Process

## Control Objective

Coordinate detection, analysis, containment, eradication, recovery, communication, and lessons learned during security incidents.

## Risk Addressed

Uncontained compromise, prolonged disruption, poor communication, evidence loss, repeated failures.

## Control Type

Corrective. Administrative and technical.

## Control Owner

VERIFY.

## Implementation Guidance

Define roles, severity model, escalation, containment authority, evidence handling, communication, recovery, legal/regulatory involvement, and lessons learned.

## Evidence

Incident plan, playbooks, incident tickets, timeline, decisions, containment actions, recovery records, lessons learned, improvement actions.

## Control Testing

Validate through tabletop exercises, technical exercises, after-action reviews, or real incident evidence. Scope and frequency: VERIFY.

## Failure Conditions

No owner, unclear severity, delayed containment, missing evidence, no lessons learned, unresolved action items.

## Metrics

MTTD, MTTR, containment time, overdue incident actions, exercise completion, recurring root causes.
