# Control - Data Loss Prevention

## Control Objective

Detect or prevent unauthorized movement, sharing, or exposure of sensitive data.

## Risk Addressed

Data leakage, accidental disclosure, insider misuse, policy violation.

## Control Type

Detective and preventive. Technical.

## Control Owner

VERIFY.

## Implementation Guidance

Define sensitive data types, policies, monitoring locations, response workflow, tuning process, and exception handling.

## Evidence

DLP policy configuration, alerts, incident tickets, tuning records, exception approvals, data classification rules.

## Control Testing

Validate that policies detect defined sensitive data patterns and that alerts are investigated and resolved.

## Failure Conditions

No classification, excessive false positives, ignored alerts, unmanaged exceptions, blind spots.

## Metrics

DLP incidents, false positive rate, unresolved alerts, policy coverage, repeat violators.
