# Control - Security Logging and SIEM

## Control Objective

Collect, correlate, alert, and support investigation of security-relevant events.

## Risk Addressed

Undetected compromise, delayed response, missing investigation evidence, control failure.

## Control Type

Detective. Technical.

## Control Owner

VERIFY.

## Implementation Guidance

Define required log sources, retention, alerting, triage workflow, ownership, detection engineering, and tuning process.

## Evidence

Log source inventory, ingestion status, detection rules, alert records, case records, retention settings, tuning records.

## Control Testing

Validate log source coverage, alert generation, triage records, and escalation to response.

## Failure Conditions

Missing critical logs, broken ingestion, noisy or absent alerts, no triage evidence, insufficient retention.

## Metrics

Log source coverage, detection coverage, MTTD, MTTR, false positive trends, critical ingestion failures.
