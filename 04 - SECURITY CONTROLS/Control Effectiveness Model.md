# Control Effectiveness Model

## Overview

Control effectiveness describes whether a control reduces risk as intended. Maturity describes how repeatable and optimized the control capability is. They are related but not identical.

## Maturity Scale

| Level | Name | Description |
|---|---|---|
| 0 | Not Implemented | Control does not exist or is not operating |
| 1 | Ad Hoc | Control exists informally and inconsistently |
| 2 | Partially Implemented | Control exists in some areas but has gaps |
| 3 | Defined | Control is documented, owned, and repeatable |
| 4 | Managed | Control is measured, monitored, and tested |
| 5 | Optimized | Control is continuously improved and risk-informed |

## Effectiveness Assessment

| Assessment | Meaning |
|---|---|
| Effective | Evidence supports that the control addresses the risk in scope |
| Partially Effective | Evidence shows meaningful risk reduction with gaps |
| Ineffective | Evidence shows the control does not address the risk sufficiently |
| Not Determined | Evidence is insufficient |

## Important Distinction

A control can be mature but ineffective if it is well documented yet poorly designed for the risk. A control can be effective in a narrow scope but immature because it depends on manual effort or undocumented knowledge.
