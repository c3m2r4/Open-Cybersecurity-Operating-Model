# Control Framework Mapping Guide

## Purpose

Framework mapping helps organize controls and communicate alignment. It does not prove compliance.

## Mapping Language

| Phrase | Use |
|---|---|
| Framework alignment | Safe wording for conceptual relationship |
| Mapped to | Use when a specific control relationship is documented |
| Compliant with | Use only after formal scope, evidence, and assessment |

## Frameworks

Use framework mapping where meaningful:

| Framework | Useful For |
|---|---|
| NIST CSF | Cybersecurity outcome organization |
| NIST RMF | Risk and control lifecycle concepts |
| ISO/IEC 27001 | Information security management controls |
| CIS Controls | Practical safeguard categories |
| COBIT | Governance and management objectives |
| PCI DSS | Payment card data environments, if applicable |
| MITRE ATT&CK | Technical adversary behavior and detection alignment |

Verify current framework versions before publication or formal assessment.
